# Eco-Efficient Cascade Architecture of Gradient-Boosted Tree Methods for Credit Card Fraud Detection

This repository contains the code, experimental notebooks, figures, and tables accompanying the research paper:

**Eco-Efficient Cascade Architecture of Gradient-Boosted Tree Methods for Credit Card Fraud Detection**

The study investigates an eco-efficient two-stage cascade architecture for credit-card fraud detection and evaluates predictive performance alongside computational and environmental efficiency.
